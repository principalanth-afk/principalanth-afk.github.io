¿Qué hace un minero?

Bitcoin es como un gran cuaderno público donde se anotan todos los pagos. Cada ~10 minutos se agrega una página nueva, llamada bloque.

Para ganarse el derecho de escribir esa página, las máquinas del mundo compiten resolviendo un acertijo: buscar un número (el nonce) que, mezclado con la página, dé una “huella” (hash) que empiece con muchos ceros.

No hay truco: solo probar y probar, millones de millones de veces por segundo. Eso es el hashrate. Quien encuentra primero la huella gana bitcoins nuevos.

📖 Palabras de minero

Hashrate (TH/s)
Intentos por segundo. 1 TH/s = un billón (1.000.000.000.000) de intentos cada segundo.
Hash o huella
Un código que sale de mezclar datos con la fórmula SHA-256. Si cambias una sola letra, sale una huella totalmente distinta.
Nonce
El número que el minero va cambiando (0, 1, 2, 3…) hasta que la huella sale con suficientes ceros.
Dificultad
Cuántos ceros exige la red. Cada cero de más hace el trabajo 16 veces más difícil.
Pool
Un equipo de mineros de todo el mundo que suman fuerzas y se reparten el premio según cuánto trabajó cada uno.
Share (acción)
Una “casi solución” que el minero manda al pool para demostrar que está trabajando. Así el pool sabe cuánto pagarle.
Consumo (W) y eficiencia (J/TH)
Cuánta electricidad gasta. La eficiencia dice cuánta energía cuesta cada TH: menos es mejor.
Temperatura
Los chips se calientan mucho. Los ventiladores los enfrían; si se calientan de más, el minero baja la velocidad o se apaga para protegerse.
